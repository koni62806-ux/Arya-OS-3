# Arya Keyboard

A lightweight Android input method for Persian and English. This is a real Android IME project, not a keyboard mockup.

## First version

- Persian and English letter layouts with a language toggle
- Space, comma, backspace and enter/action key
- Dark navy keys with blue accents
- Android system input-method activation and picker
- No network permission or network-based typing

## Build the APK

GitHub Actions builds a debug APK on pushes that change this folder, and can also be started manually from the Actions tab.

After a successful run, download the artifact named Arya-Keyboard-debug. Extract it and install app-debug.apk on the Samsung phone. You may need to allow installation from the browser or file manager used to open the APK.

## Enable on Samsung

1. Open Arya Keyboard once.
2. Tap فعال‌سازی Arya Keyboard and enable it in Samsung's keyboard list.
3. Return to the app and tap انتخاب کیبورد, then choose Arya Keyboard.
4. Test it in a harmless text field.

## Privacy and limitations

The app requests no internet permission and does not collect or transmit typed text. This initial build does not yet include predictive text, swipe typing, emoji panel, clipboard, voice input, number/symbol pages, or a polished settings screen. Review and test the APK before relying on it as your only keyboard.
