# Arya Center

A lightweight GTK 3 application hub for Arya OS. It provides shortcuts to core desktop apps and discovers offline HTML games installed under `/usr/share/arya/games/<game-name>/index.html`.

Games open in Firefox ESR as local files; no remote game assets are required by the launcher. Game packages must include their complete assets and be reviewed for licensing and unsafe network dependencies before inclusion.

This first iteration is a functional application launcher, not a replacement desktop shell or a full Start-menu/dock implementation.
